# Security Policy

## Authorized use

Use WebGuard only against systems you own or have explicit permission to assess. Follow the system owner's scope, rate limits, and disclosure process. Start with passive mode. Active probes are opt-in, send only a harmless HTML marker and a single quote in existing nonsensitive query parameters, and must only be used where GET requests are safe. Do not use the tool to bypass access controls, disrupt services, brute-force accounts, or access data beyond the approved scope.

## Reporting

For a vulnerability in this project, report it privately to the repository maintainer with a concise reproduction and impact assessment. Do not include secrets or third-party personal data in public issues.
